# Catálogo de Videojuegos — Full-Stack App

Aplicación web full-stack para la gestión y visualización de un catálogo de videojuegos, con autenticación de usuarios mediante GitHub OAuth, roles (`user` / `admin`) y panel de administración CRUD.

## Enlaces de Producción (Render)

* **Frontend (Aplicación Web):** https://tp-videojuegos-frontend.onrender.com
* **Backend (API REST):** https://tp-videogames-backend.onrender.com

## Tecnologías Utilizadas

* **Frontend:** React, TypeScript, Vite, React Router.
* **Backend:** Node.js, Express, TypeScript, Mongoose, Zod.
* **Base de Datos:** MongoDB Atlas.
* **Autenticación:** Better Auth (GitHub OAuth + control de roles).
* **Despliegue:** Render (Static Site + Web Service).
